# Guide Client

1. Telecharger `RelaisDesk-Setup.exe`.
2. Lancer l'installeur en administrateur.
3. Entrer la cle de licence.
4. Attendre la validation et la configuration de RustDesk.
5. Lancer le raccourci RelaisDesk.

## Depannage

- Cle refusee : verifier que la licence est active et non expiree.
- Serveur inaccessible : vérifier la connexion Internet et l’accès aux ports RustDesk Community `21116`/`21117`.
- Windows SmartScreen : utiliser un installeur signe en production.
