FAQ

Questions fréquentes

Tout ce que vous devez savoir sur le fonctionnement de RelaisDesk.

Vos clients téléchargent l'application Client légère. Depuis votre application Technicien, vous générez un code unique de 8 caractères (ex: AB12-CD34). Le client saisit ce code et RustDesk rejoint directement notre serveur auto-hébergé.
Chaque code d'assistance est valide pendant 12 heures. Vous pouvez en générer un nombre illimité chaque jour pour vos interventions, quel que soit votre plan (Starter, Pro ou Ultra).
L'application Client est 100% gratuite et sans abonnement pour vos clients finaux. Si vous le souhaitez, vous pouvez cependant activer l'option Prestations Stripe Connect pour leur facturer directement vos dépannages au forfait ou au temps passé.
Par carte bancaire (Stripe), votre licence est créée immédiatement et envoyée par email avec vos identifiants. Par virement bancaire, la licence est activée dès réception des fonds par notre administration. Les abonnements peuvent aussi être réglés en Bitcoin ou XRP lorsque ce moyen est proposé au récapitulatif.
Windows (.exe) et Linux (.deb) sont proposés. macOS n’est pas encore disponible publiquement. L’accès permanent nécessite Windows et les services compatibles installés ; il n’est pas disponible sous Linux ou macOS.
Oui. RelaisDesk intègre en option la facturation de vos prestations via Stripe Connect. Depuis votre application Technicien, choisissez « Connexion & Prestation » pour facturer un forfait prépayé ou au temps réel connecté (tarif horaire calculé à la minute). Le client règle directement par carte bancaire via Stripe Checkout.
